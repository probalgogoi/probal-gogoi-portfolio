# Rishi Gogoi — Personal Portfolio

A minimal editorial portfolio inspired by the visual principles of huyml.co:
oversized typography, restrained layout, high-contrast editorial sections,
project-list navigation, large imagery and subtle motion. It is an original
implementation, not a copy of the source site's code or assets.

## Included
- Responsive one-page portfolio
- Rishi identity and biography
- Actual projects only (no future-project/idea section)
- My Mind Ray live link
- Northeast India Discord community
- YouTube channel
- Education history
- Skills and languages
- Interests and favourites
- Uploaded/cropped personal photos
- Scroll-reveal animation and desktop cursor detail

## Run
Open `index.html`, or use:
python -m http.server 5500

## Deploy
Upload the folder to Vercel, Netlify, GitHub Pages, or another static host.
